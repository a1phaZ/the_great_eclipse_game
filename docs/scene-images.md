# Промпты для генерации изображений сцен

Контент-пак `great_eclipse`: **13 локаций, 318 сцен**.
Формат изображений: **1:1, 1440×1440**, WebP или JPG — квадрат одинаково хорошо смотрится в чате Telegram на телефоне и не выталкивает подпись с кнопками за экран.

Статика раздаётся через GitHub raw: `https://raw.githubusercontent.com/a1phaZ/the_great_eclipse_game/main/images/<файл>`. Поэтому `imageUrl` сцены — это raw-ссылка на файл из `images/`.
Пока реальная картинка есть только у `new_detroit:prologue`; у остальных сцен `imageUrl` — заглушка `https://unsplash.com`. Имена файлов в таблицах — предложение под будущую загрузку.

## Как собрать итоговый промпт

```
MASTER STYLE + Prompt из таблицы + NEGATIVE
```

### MASTER STYLE (общий для всех сцен)

```text
Masterpiece post-apocalyptic dieselpunk concept art, cinematic keyframe, gritty painterly realism,
muted earth palette of rust orange, ash grey, dust ochre and cold teal shadows, heavy salt dust and
diesel haze in the air, weathered steel, cracked paint, improvised armor plating, analog 1980s
technology, brutalist concrete, volumetric light shafts, dramatic chiaroscuro, deep shadows, subtle
film grain, ultra-detailed textures, square 1:1 composition with the main subject centered, sky and
atmosphere in the upper half, a clean uncluttered lower edge that will sit above the caption, balanced
negative space, atmosphere of a dying world under a darkened sun, no text, no lettering, no logos,
no watermarks
```

### NEGATIVE (общий для всех сцен)

```text
text, letters, captions, UI, watermark, logo, signature, cartoon, anime, cute, colorful, clean,
pristine, modern glossy, plastic, oversaturated, low detail, blurry, distorted anatomy, extra wheels,
deformed vehicle, fisheye lens, cropped
```

### Правила

- Для сцен с экранами, досками и голограммами в `Prompt` уже указано `unreadable glyphs` — модель не должна рисовать осмысленный текст.
- В колонке **Reuse** — сцены, которым подойдёт та же картинка. Формат `locationId:sceneId`.
- Имя файла: `<locationId>_<sceneId>.webp` или `<locationId>_<sceneId>.jpg`.
